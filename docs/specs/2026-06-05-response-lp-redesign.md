# 反応型LPリニューアル設計（蜂の巣駆除ファクトリー東海）

- **日付**: 2026-06-05
- **ブランチ**: `redesign/response-lp`
- **対象**: `src/pages/index.astro` + `src/styles/global.css`
- **参照（ユーザ指定の目標見た目）**: `an-shin-homeservice.com/lp-hachi01/toukai/`
- **本番**: https://hachi-factory.jp

## 1. 目的 / 成功条件

ユーザが「見た目が好み」と名指しした日本の**反応型LP**（写真主導・高彩度・高密度・大きい価格・追従CTA）の見た目に寄せる。ただし**中身は捏造数字なしの正直版**で固定。

**成功条件（何が見えれば完了か）**:
1. モバイルのヒーローが「写真主導・大きい価格・即時CTA」で参照と同等の熱量に見える
2. 全セクションに反応型の装置（黄バンドheaders/黒黄STEP/反復CTA帯/信頼バッジ/追従バー）が入る
3. コピーの正直さ・景表法対応・SSOT・構造化データ6種を維持
4. PSI/Lighthouse スコアが現状以上（9.0+目標）。参照(画像LP)より検索評価で勝つ
5. 7 viewport で破綻なし

## 2. 戦略的コア

参照LPは**全コンテンツがPhotoshop焼き込み画像スライス**（実テキスト41文字／`<section>`10個が画像）。視覚制御は高いが SEO/AEO/速度/a11y/更新性が弱い。
→ **同じ見た目を本物のHTML/CSSで再現**し、検索評価・速度・構造化データで全勝ちする。これがリニューアルの核。

## 3. 確定した方針（Phase 0 合意）

| 項目 | 決定 |
|---|---|
| 写真 | AIイメージ主導（「※写真はイメージ」明示）＋実例1件は本物Before/After |
| 価格 | ¥1,680を大きく正直に。熱量は「追加料金0円／出張・見積無料／1年保証」。打消し線・%OFF演出はしない |
| 範囲 | ゼロから再設計OK（正直・景表法は維持） |

## 4. 現状診断

- 配色トークンは**既に正解**（primary赤`#c81e1e`／accent黄`#f5b300`／cream`#fbf6ec`／line緑`#06c755`）
- IAも既に参照とほぼ同じ（hero/troubles/strengths/bee-types/pricing/compare/cases/voices/flow/areas/faq/contact）
- **ギャップは純粋に「鳴らし方」**: クリーム多めで彩度が眠い／ヒーローが文字主導＆暗い木目／価格に見せ場がない／節headersが地味／flowにバッジなし／CTA帯の反復が弱い／追従バーが控えめ

## 5. 移植する8つの反応型装置

1. **写真主導ヒーロー** — AI実写級画像（「※イメージ」）を主役に。問題サムネ4枚帯。大きい価格ブロック。
2. **お悩みサムネ4枚帯** — troublesを写真化（軒下/出入り/ベランダ/室外機）
3. **大きい価格ブロック** — ¥1,680を巨大表示＋「追加料金0円」帯（打消し線なし）
4. **黄バンド節headers** — 「選ばれる3つの理由」型。黄背景＋特大番号
5. **黒×黄STEPバッジ** — flowをSTEP01-05＋下三角コネクタ
6. **反復CTA帯** — 区切りごとにphone+LINE+「見積0円」を反復（mid-cta増設）
7. **信頼バッジ3〜4連** — 出せる数字だけ（最短30分/見積¥0/1年保証/24時間365日）。**「累計10万件」は出さない**
8. **追従フッターバー** — floating-ctaを高コントラスト常時バー化（モバイル）

## 6. デザインシステム変更

- **彩度を面で使う**: hero/価格/CTA帯/節headers を赤・黄のベタ面に。本文は可読性維持
- **密度**: セクション余白を詰める。各セクションに写真
- **タイポ**: 見出しの級数を上げ、白フチ/影で力強く（反応型の極太ゴシック感）
- **黒黄の業務的アクセント**（STEPバッジ・バッジ枠）を追加

## 7. 変えないもの（不可侵）

- コピーの正直さ／景表法（最安・捏造数字・無根拠比較の禁止）
- SSOT（`src/data/*`）の事実
- 構造化データ6種・CSP・WebP・パフォーマンス予算
- AI画像の「※イメージ」明示

## 8. ビルド順序

1. デザインシステム土台（global.css にトークン/ユーティリティ追加）
2. **ヒーロー再構築**（写真主導・大価格・サムネ帯）→ 本番未反映のまま screenshot し参照/現行と3面比較（control point）
3. 承認後、節headers/価格/flow/CTA帯/信頼バッジ/追従バーを全展開
4. 7 viewport 監査・微修正
5. Phase 6: 実URL(プレビュー or 本番) で PSI/Lighthouse/リッチリザルト検証
6. 問題なければ main へマージ→本番反映

## 9. リスクと回避

- **本番LPは広告流入中** → 作業は `redesign/response-lp` ブランチで隔離。検証完了までmainに触れない
- **彩度を上げすぎて安っぽくなる** → 反応型の中でも「信頼が出るトーン」に寄せる（参照より少し締める）。3面比較で都度判断
- **写真の質バラつき** → 既存AI資産は実写級。不足分のみ追加生成、全て「※イメージ」明示
